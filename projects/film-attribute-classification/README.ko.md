# 영화 속성 다중 레이블 분류

[English](README.md) | [한국어](README.ko.md) | [포트폴리오 홈](../../README.ko.md)

## 개요

영화 제목과 줄거리에서 다음 8개 속성을 복수로 분류하는 프로젝트입니다.

`comedy`, `cult`, `flashback`, `historical`, `revenge`, `romantic`, `scifi`, `violence`

레이블 불균형, 긴 입력, GPU 제약, 레이블별 의사결정 경계를 고려하면서 순환 신경망 기준 모델과 두 개의 사전학습 트랜스포머 파이프라인을 비교했습니다.

## 모델 비교

| 모델 | 주요 기법 | 검증 weighted F1 |
| --- | --- | ---: |
| [BiLSTM + 어텐션](notebooks/bilstm-attention.ipynb) | GloVe 임베딩, 사용자 정의 어텐션, Asymmetric Loss | 0.5845 |
| [RoBERTa-base](notebooks/roberta.ipynb) | 파인튜닝, 혼합 정밀도, 계층별 학습률 감소 | **0.6253** |
| [DeBERTa-v3 앙상블](notebooks/deberta-ensemble.ipynb) | 마스킹 평균 풀링, 3개 학습 시드, 소프트 보팅 | 0.6142 |

DeBERTa-v3의 최고 단일 시드는 0.6223을 기록했으며 표에는 최종 앙상블 점수를 적었습니다. 이 데이터셋에서는 더 복잡한 DeBERTa 파이프라인보다 RoBERTa-base가 가장 높은 검증 성능을 보였습니다.

## 엔지니어링 설계

### 클래스 불균형

모든 모델에 Asymmetric Loss를 적용해 쉽게 분류되는 음성 예제의 기여도를 낮추고 어려운 양성 레이블에 대한 학습 신호를 유지했습니다. 하나의 0.5 임계값을 일괄 적용하지 않고 검증 예측에서 각 레이블에 적합한 임계값을 별도로 탐색했습니다.

### 긴 텍스트와 풀링

- BiLSTM 파이프라인은 300차원 GloVe 임베딩과 최대 1,400개 토큰을 사용합니다.
- RoBERTa와 DeBERTa의 입력 길이는 최대 512개 토큰입니다.
- DeBERTa 분류기는 하나의 분류 토큰에만 의존하지 않고 어텐션 마스크가 유효한 토큰 상태를 평균 풀링합니다.

### 연산 자원 제약

- 자동 혼합 정밀도로 트랜스포머 학습 중 GPU 메모리 부담을 줄였습니다.
- RoBERTa 파이프라인은 계층별 학습률 감소를 적용해 하위 계층의 사전학습 표현을 보존했습니다.
- DeBERTa 파이프라인은 시드 16, 42, 378을 독립적으로 학습하고 추론 시 확률을 평균했습니다.

## 노트북 실행

상대 경로가 올바르게 해석되도록 이 디렉터리에서 Jupyter를 시작합니다. 설치 및 import 셀을 먼저 실행한 뒤 선택한 파이프라인을 순서대로 실행합니다. BiLSTM 노트북은 GloVe 임베딩을, 트랜스포머 노트북은 Hugging Face 사전학습 모델을 내려받습니다. CUDA 지원 GPU 사용을 권장합니다.

체크포인트, 내려받은 가중치, 실험 추적 도구 파일, 원시 로그, 중간 검증 예측은 Git에서 제외합니다. 정리된 최종 예측은 [`results/`](results/)에 유지했습니다.

## 결론

모델 비교 결과 추가적인 구조적 복잡성이 반드시 더 좋은 성능으로 이어지지는 않았습니다. RoBERTa-base가 가장 높은 검증 점수를 기록했고, DeBERTa 앙상블은 시드에 따른 변동과 확률 앙상블 효과를 살펴보는 사례가 되었습니다. 모든 구조에서 가장 일관된 개선은 손실 함수 설계와 의사결정 임계값 보정을 다중 레이블 파이프라인의 핵심 요소로 다룬 데서 나왔습니다.
